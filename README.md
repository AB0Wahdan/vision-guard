# 🛡️ Vision Guard

> AI surveillance system for real-time violence and threat detection in video

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![Deep Learning](https://img.shields.io/badge/Deep%20Learning-1f6feb?style=flat-square) ![OpenCV](https://img.shields.io/badge/OpenCV-1f6feb?style=flat-square)

## 📌 Overview
Graduation project (Ain Shams University, Faculty of Computer Science — AI specialization, Grade **A-**). Vision Guard analyzes video streams and flags violent behavior and potential threats, helping security operators respond faster.

## ✨ Features
- Real-time video analysis
- Violence / threat classification
- Alerting on detected incidents
- Works on recorded footage and live camera input

## 🛠️ Tech Stack
Python, Deep Learning, OpenCV

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python main.py --source path/to/video.mp4
```
